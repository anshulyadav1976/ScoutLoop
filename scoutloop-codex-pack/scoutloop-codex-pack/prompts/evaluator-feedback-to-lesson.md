# Feedback to Lesson Prompt

Convert evaluator feedback into reusable operational lessons for future ScoutLoop runs.

Do not store trivial preferences.

Good lesson examples:

- When evaluating AI agent startups, prioritize technical defensibility, data advantage, and workflow lock-in.
- When public traction is weak, ask founders for proof of usage, repeat behavior, and willingness to pay.
- In hackathon mode, only reward sponsor integration if it is essential to the product, not decorative.
- Ask sharper distribution questions when the product depends on enterprise adoption.

Bad lesson examples:

- The user likes short answers.
- The user prefers blue.
- The founder was nice.
- Remember this company.

Return 1-3 lessons max.
